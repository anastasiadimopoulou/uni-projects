# ΠΧ2 ΕΙΣΟΔΟΣ ΣΤΗΝ ΕΦΑΡΜΟΓΗ

**Πρωτεύον Actor:**  Χρήστης

**Ενδιαφερόμενοι:** 

Χρήστης: Θέλει να κάνει είσοδο στο σύστημα.

Καθηγητής : θέλει να  κάνει είσοδο για να διαχειρίζεται τα μαθήματα  του και την τράπεζα ερωτήσεων του.

Φοιτητής : θέλει να κάνει είσοδο στην εφαρμογή ετσι ώστε να συμπληρώσει διαγωνίσματα και να εξασκηθεί.

**Προϋποθέσεις:** 
Να έχουν εκτελεστεί επιτυχώς οι περιπτώσεις χρήσης "Εγγραφή ως καθηγητής" καθώς και η περίπτωση χρήσης "Εγγραφή ως φοιτητής".

# Βασική Ροή
1. Ο χρήστης ανοίγει την εφαρμογή
2. Το συστημα εμφανίζει ένα μενού επιλογών στον χρήστη με τις εξής λειτουργίες "Είσοδος ","Δημιουργία λογαριασμού φοιτητή"και "Δημιουργία λογαριασμού καθηγητή".
3. Ο χρήστης επιλέγει λειτουργία "Είσοδος".
4. Το σύστημα ζητάει username/password του χρήστη.
5. Ο χρήστης εισάγει username/password.
6. Το σύστημα ελέγχει ορθότητα username/password.
7. Ορθά στοιχεία χρήστη username/password ,αντιστοιχούν σε λογαριασμό.
8. επιτυχής είσοδος στο σύστημα και εμφάνιση  βασικού μενού της εφαρμογής στο χρήστη που περιέχει βασική λιστα με μαθήματα που έχουν δημιουργηθεί καθώς και λειτουργίες όπως "δημιουργία μαθήματος" ,"εξοδος από εφαρμογή".

**Εναλλακτικές Ροές**

*3α.O χρήστης δεν επιλέγει καμία λειτουργία*
1. παραμένει ο χρήστης στο μενού επιλογών.

*7α.Λάθος στοιχεία χρήστη  username/password , δεν αντιστοιχούν σε λογαριασμό.*
1. Το σύστημα εμφανίζει αντίστοιχο μήνυμα("Τα στοιχεία δεν αντιστοιχούν σε λογαριασμό")   
2. Πήγαινε στο βήμα 5 της βασικής ροής.
