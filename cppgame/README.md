#C++  Platform Game with SGG Library

## Description
This is a 2D platform-style game developed in C++ using the SGG (Simple Game Graphics) library as part of a university assignment at AUEB.

The player controls a character that progresses through multiple levels by passing through portals that lead to the next stage. In each level, the player collects diamonds to increase their score while avoiding enemies that reduce health upon collision.

---

## Gameplay
The player moves through different levels using portals that connect each stage.

In every level, the objective is to collect all diamonds while avoiding enemies. Enemies reduce the player's health upon contact, and the game ends if the player's health reaches zero.


---

## Features
- Player movement and controls
- Multiple levels / scene transitions via portals
- Collectible items (diamonds)
- Enemy entities with collision mechanics
- Health and score system
- Game loop implemented using SGG framework

---

## Technologies Used
- C++
- SGG (Simple Game Graphics) Library
- Object-Oriented Programming (OOP)
